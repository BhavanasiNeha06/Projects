# 🍽️ Restaurant Menu System

A simple Java-based Restaurant Menu System that allows users to manage restaurant menu items efficiently. The application provides basic menu management functionalities such as adding, viewing, updating, and deleting food items through a user-friendly interface. It is designed to demonstrate core Java programming concepts and object-oriented programming principles.

---

## 📌 Features

- ➕ Add new menu items
- 📋 Display all available menu items
- ✏️ Update existing menu items
- ❌ Delete menu items
- 🔍 Search menu items
- 💰 Store item prices and categories
- 🖥️ Console-based interactive interface

## 🚀 Getting Started

### Prerequisites

- Java JDK 8 or above
- Any Java IDE (Eclipse, IntelliJ IDEA, VS Code)

### Installation

1. Clone the repository

```bash
git clone https://github.com/BhavanasiNeha06/Projects.git
```

2. Navigate to the project folder

```bash
cd Projects/RestaurantMenuSystem
```

3. Compile the project

```bash
javac *.java
```

4. Run the application

```bash
java Main
```

---

## 📖 How It Works

1. Launch the application.
2. Select an option from the menu.
3. Add, update, delete, or view restaurant menu items.
4. The system displays the updated menu after each operation.
